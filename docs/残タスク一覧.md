3. 012 除外管理
   - 誤送信防止に関わるため、X API候補抽出や本格運用前に実装する
   - 候補一覧/詳細から除外し、除外リストで復元できるようにする
4. 018 ダッシュボード集計表示
   - 候補、送信済み、除外、キュー状況を実データで把握できるようにする
   - 011/012/019のデータ表示が揃った後に実装すると集計項目が安定する
5. 013 成果証跡管理
   - 送信履歴を参照して成果登録できるようにする
   - 契約上の証跡として候補/履歴/報酬率のスナップショットを保存する
6. 014 X API検証
   - X Developer App、OAuth、投稿検索、DM可否を検証する
   - API DM送信をMVP必須にしない判断を維持する
7. 015 X API候補抽出
   - 014で投稿検索/ユーザー取得が利用可能と判断できた後に実装する
   - 除外/既送信判定を反映して `candidates` に保存する
8. 016 API DM送信
