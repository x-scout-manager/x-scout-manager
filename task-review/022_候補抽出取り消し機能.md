# 022 候補抽出取り消し機能レビュー

## 2026-05-18 実装メモ

ユーザー指摘:

- 誤った条件で候補抽出した場合に、その抽出をなかったことにしたい
- 候補抽出データは即DBに入るため、DB上の扱いを明確にしたい

対応:

- `candidate_sync_runs/{runId}` を追加
- `candidate_sync_runs/{runId}/changes/{candidateId}` に候補ごとの差分を保存
- `syncCandidates` の戻り値に `runId` を追加
- `revertCandidateSyncRun` callableを追加
- 候補一覧画面に最近の候補抽出履歴と解除ボタンを追加
- Firestore Rulesで抽出履歴をadmin read / Functions writeにした

解除時の保護:

- 送信履歴がある候補はスキップ
- 送信キューitemがある候補はスキップ
- 後続抽出で更新済みの候補はスキップ

検証:

```text
npm --prefix functions run build: pass
flutter analyze: pass
flutter test: pass
```
