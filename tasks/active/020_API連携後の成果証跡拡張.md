# 020 API連携後の成果証跡拡張

## 現状の動作

成果証跡は手動送信支援モードで作成された `send_histories` を起点に登録する。

## 期待する動作

X API連携後に、API由来の送信・抽出・DMイベント情報も成果証跡へ保存できる。

## 操作フロー

1. X API連携後の送信履歴または候補を確認
2. API由来の証跡情報を含めて成果登録
3. 成果一覧でAPI由来証跡を確認

## UI参考（既存画面）

- `ConversionListPage`
- `SendHistoryPage`
- `CandidateDetailPage`

## 技術方針

013の `conversions` 基盤を維持し、API連携後に追加される `xDmEventId`、投稿ID、APIレスポンス由来の証跡をスナップショットへ追加する。

## 対象ファイル（推定）

- `functions/src/index.ts`
- `lib/features/conversions/**`
- `lib/features/histories/**`
- `lib/features/candidates/**`

## 完了条件

- API送信履歴から成果登録できる
- API由来のDMイベントIDまたは投稿IDを成果証跡に保存できる
- 既存の手動送信支援モードの成果登録が壊れない

## レビュー指摘

013実装時に、API連携後の証跡拡張として分離。
