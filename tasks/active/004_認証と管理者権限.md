# 004 認証と管理者権限

## 現状の動作

ログイン画面は静的表示のみで、認証・権限判定が未実装。

## 期待する動作

Firebase Authenticationでログインし、`users/{uid}` によるadmin判定で管理画面を保護する。

## 操作フロー

1. ログイン情報を入力
2. Firebase Authenticationでログイン
3. `users/{uid}` を取得
4. adminかつ有効ならダッシュボードへ遷移
5. 未ログインまたは権限なしは拒否
