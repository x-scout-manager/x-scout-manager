# 013 成果証跡管理

## 現状の動作

送信履歴を起点に成果証跡を登録し、成果一覧で確認できる。

## 期待する動作

候補・送信履歴に紐づく成果証跡を登録できる。

## 操作フロー

1. 成果報告管理画面を開く
2. 送信履歴を選択
3. 対象売上を入力
4. 報酬額を計算
5. 成果登録

## UI参考（既存画面）

- `ConversionListPage`
- `ConversionListPage`

## 技術方針

登録時点の候補・送信履歴・報酬率をスナップショット保存する。
初期実装では手動送信支援モードで作成された `send_histories` を成果登録の起点にする。
