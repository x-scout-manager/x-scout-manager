# 012 除外管理

## 現状の動作

候補詳細から除外/復元でき、除外リストから復元できる。

## 期待する動作

候補を除外し、除外リストから確認・復元できる。

## 操作フロー

1. 候補詳細で除外
2. `excluded_accounts` に保存
3. 候補状態が除外になる
4. 除外リストで確認
5. 必要なら復元

## UI参考（既存画面）

- `CandidateDetailPage`
- `ExcludedAccountPage`

## 技術方針

除外対象の正本は `excluded_accounts`。

## 対象ファイル（推定）

- `functions/src/index.ts`
- `lib/features/exclusions/**`
- `lib/features/candidates/**`
- `lib/app/di/providers.dart`

## 完了条件

- [x] 除外対象は送信キュー化されない
- [x] 復元時に既送信ならsentを維持する
- [x] Functions/Flutterの検証が通る

## レビュー指摘

- 候補一覧からの直接除外は未実装。詳細画面から除外する導線で対応。
- 復元時、除外化済みの古い送信キュー明細は自動で `pending` に戻さない。
  復元後に必要であれば新しい送信キューを作成する。
