# 024 送信キュー明細読み込み修正と削除

## 現状の動作

- 送信キュー作成直後は表示できる場合がある。
- 別画面へ移動後に送信キュー画面へ戻ると、送信キュー明細の読み込みに失敗する。
- 明細が読めないため、送信対象が未選択となりAPI送信ボタンも有効化されない。
- 送信キューを画面から削除できない。

## 期待する動作

- 管理者は送信キュー明細を安定して読み込める。
- 送信対象とテンプレートが揃えば、本文プレビューとAPI送信ボタンが有効になる。
- 不要な送信キューを画面から削除できる。
- 削除しても送信履歴、候補データ、除外データは削除しない。

## 操作フロー

1. 候補一覧から送信キューを作成する。
2. 別画面へ移動する。
3. Drawerの送信キューから対象キューへ戻る。
4. 送信対象、テンプレート、本文プレビューが表示される。
5. 必要に応じて「キュー削除」を押す。
6. 確認ダイアログで削除を確定すると、送信キュー一覧へ戻る。

## 技術方針

- `send_queues/{queueId}/items/{itemId}` のFirestore Rulesにadmin readを追加する。
- 送信キュー削除はCloud Functions経由の論理削除にする。
- `send_queues.status = deleted`、`deletedAt`、`deletedBy` を保存する。
- Flutter側では `deleted` の送信キューを一覧から非表示にする。
- Cloud Functions本体は `functions/src/send_queue/delete_send_queue.ts` に配置し、`index.ts` はexportのみ行う。

## 完了条件

- 送信キュー画面へ戻っても明細読み込みエラーが出ない。
- 明細が読める場合、送信対象が選択され本文プレビューが表示される。
- API DM送信設定ONかつ本文がある場合、API送信ボタンが有効になる。
- 送信キューを削除すると一覧から非表示になる。
- `flutter analyze` が通る。
- Cloud Functionsのbuild/lint/testが通る。
- Firestore Rules、Functions、Hostingへ反映できる。

## レビュー指摘

- 別画面から送信キュー画面へ戻ると「送信キュー明細の読み込みに失敗しました」となる。
- 送信対象が未選択になりAPI送信ボタンが有効化されない。
- 送信キュー画面で送信キューを削除できるようにしたい。

## 備考

- 削除は納品前の操作性改善として実施する。
- 物理削除は送信履歴の参照や監査性を損なうため採用しない。
