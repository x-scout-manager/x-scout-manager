# 004 認証と管理者権限

## 現状の動作

ログイン画面はFirebase Authenticationと接続済み。

`users/{uid}` の `role = admin` かつ `isActive = true` で管理者判定する。

管理画面ルートは `AuthGate` で保護済み。

## 期待する動作

Firebase Authenticationでログインし、`users/{uid}` によるadmin判定で管理画面を保護する。

## 操作フロー

1. ログイン情報を入力
2. Firebase Authenticationでログイン
3. `users/{uid}` を取得
4. adminかつ有効ならダッシュボードへ遷移
5. 未ログインまたは権限なしは拒否
