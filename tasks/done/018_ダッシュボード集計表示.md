# 018 ダッシュボード集計表示

## 現状の動作

ダッシュボードはFirestoreの集計クエリで実データ件数を表示する。

## 期待する動作

Firestoreの実データをもとに、主要指標をダッシュボードで確認できる。

## 表示候補

- 候補数
- 送信済み数
- 除外数
- 未送信候補数
- アクティブな送信キュー数

## UI参考（既存画面）

- `DashboardPage`
- `SummaryTiles`

## 技術方針

初期実装ではFirestoreの集計クエリまたは通常クエリで実装し、件数が増える段階でCloud Functions集計や集計ドキュメントを検討する。

## 対象ファイル（推定）

- `lib/features/dashboard/**`
- `lib/features/candidates/**`
- `lib/features/send_queue/**`

## 完了条件

- [x] ダッシュボードの固定値 `0` を廃止する
- [x] Firestoreの候補/送信済み/除外/送信キュー状態を反映する
- [x] 読み込み中、エラー、データなし状態を表示する

## レビュー指摘

- 初期実装ではCloud Functions集計ドキュメントではなく、Firestore `count()` 集計クエリで実装。
- 送信済み数は `send_histories` を正本として集計。
- 除外数は `excluded_accounts` を正本として集計。
