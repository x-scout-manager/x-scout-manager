# 031 除外済みスキップ時の追加取得と抽出結果表示

## 現状の動作

- X API候補抽出では、検索結果に除外済みアカウントが含まれても、候補登録や送信対象化は行わない。
- ただし除外済みアカウントが多いタグでは、取得件数の多くが除外済みで消費され、実際に増える候補が少なくなる可能性がある。
- 抽出結果には、除外済みでスキップされた件数が画面上で分かりにくい。

## 期待する動作

- 除外済みアカウントをスキップした場合、その分だけ追加ページを取得し、設定された目標候補数に近づける。
- 候補一覧画面の抽出結果通知に `除外済みでスキップ: N件` を表示する。

## 操作フロー

1. 除外済みアカウントが多く含まれるタグで候補抽出する。
2. Functions側で除外済みをスキップしつつ、追加ページを取得する。
3. 抽出完了後、候補一覧画面に新規/更新/除外済みスキップ件数が表示される。

## UI参考（既存画面）

- `lib/features/candidates/view/pages/candidate_list_page.dart`
- `lib/features/candidates/vm/candidate_list_vm.dart`

## 技術方針

- `syncCandidates` のページ取得ループを、単純なページ数上限だけでなく「有効候補数が目標に届くか」を見ながら継続できるようにする。
- 無限取得を避けるため、既存の `searchMaxPages` または追加上限を必ず適用する。
- 抽出runの `result` に除外済みスキップ件数を保存する。
- Flutter側の抽出完了通知と抽出履歴表示で、除外済みスキップ件数を確認できるようにする。

## 完了条件

- 除外済みスキップが発生しても、ページ上限内で追加取得される。
- 抽出完了通知に除外済みスキップ件数が表示される。
- 抽出履歴に除外済みスキップ件数が表示される。
- Flutter analyzeが通る。
- Functions build/lint/testが通る。

## レビュー指摘

- 除外アカウントが増えると、抽出しても除外アカウントばかりになる懸念がある。
- 除外済みをスキップした分、追加ページを取得して目標候補数まで探したい。
- 抽出結果に `除外済みでスキップ: N件` を表示したい。

## 備考

- X API検索クエリに大量の `-from:` を入れる方式は、クエリ長・username変更・運用負荷の理由で初期対応から外す。
- 除外判定の正本は引き続き `excluded_accounts/{xUserId}` とする。
