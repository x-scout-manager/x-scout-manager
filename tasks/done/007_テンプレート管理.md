# 007 テンプレート管理

## 現状の動作

テンプレート画面はFirestoreの `templates` コレクションと連携済み。

## 期待する動作

DMテンプレートを作成・編集・無効化できる。

## 操作フロー

1. テンプレート画面を開く
2. テンプレートを作成または編集
3. 保存
4. 送信キューで選択できる状態にする

## UI参考（既存画面）

- `TemplateListPage`

## 技術方針

`templates` コレクションを利用し、本文スナップショットは送信履歴側に保存する。

## 対象ファイル（推定）

- `lib/features/templates/**`
- `docs/DETAIL_firestore_design.md`

## 完了条件

- テンプレート一覧を表示できる
- 作成/編集/無効化ができる
- `flutter analyze` と `flutter test` が通る
